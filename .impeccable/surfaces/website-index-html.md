## Scope

`website/index.html` — the Chostty landing page. Mode: Persuade. One page, English, GitHub Pages.

## Audience and job

Ghostty users on macOS first, then users of other macOS terminals. They must understand the Workspace → Tab → Pane hierarchy, trust that their Ghostty config carries over, and download the DMG. Proof is the hierarchy working under their own fingers; no testimonials, counts or benchmarks exist.

## Direction contract

Seed key: b43fb65d (assigned, keycap legend sheet).

THESIS: The page is a keyboard legend sheet for one window. Shortcuts are the product's grammar, so pressing them is the proof. It refuses the dark-hero-plus-screenshot-plus-feature-grid page every terminal ships.

OWN-WORLD: Icon indigo plate as the ground with a faint 1u key pitch only where keys sit. Keycaps in the icon's dark interior, modifiers in deep violet, the selected-workspace amber and prompt coral as the only accents. Legends set in a condensed engraved-feeling sans, caps, tight; body in a hyperlegible sans; mono only for config and commands. Keys have real travel: top face, skirt, shadow with offset and blur, a pressed state that sinks.

STORY: See the window and the keys together, press one, watch a workspace appear; learn the three levels; learn the config is Ghostty's; download.

FIRST VIEWPORT: Headline and one-line offer upper left. The live Chostty window dominates the right two thirds, sidebar showing workspaces and tabs, split panes inside. Beneath it a row of real keycaps (⌘N ⌘T ⌘D ⌘B ⌘1–3) labelled with their action. A wide Return-shaped key "Download for macOS" with version and requirement below the headline.

FORM: Keycap legend system; the window is the one object, the keys its controls.

SIGNATURE: Physical keyboard and on-screen keys drive the same state machine: workspaces, tabs and panes are created, selected and focused; the focused pane is the brightest, others dim. Works with click and touch, announced to assistive tech.

## Raises carried from declined challengers

- From the oscilloscope bench: the window is one screen, many signals — every state change happens in the same frame, never a new view.
- From the silkscreen loft: the same window pulled in several Ghostty themes to prove config carries over.
- From the memory quilt: every feature caption carries its real legend — shortcut or config key.
- From the alien understory: focus is luminance; the focused pane is the only bright one.
