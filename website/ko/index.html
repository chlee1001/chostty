모든 프로젝트를 창 하나에.

Chostty는 macOS용 Ghostty 포크예요. 탭마다 창을 따로 여는 대신 워크스페이스, 탭, 분할 창을 한 창에 모아 사이드바에서 관리해요. 쓰던 Ghostty 설정 파일도 고치지 않고 쓸 수 있어요.

macOS용 다운로드

1.0.0 · Apple 실리콘·Intel · macOS 13 이상 · Apple 공증 · 무료, MIT

키를 클릭하거나 키보드로 글자만 눌러 보세요. ⌘N과 ⌘T는 브라우저가 먼저 가져가서 여기서는 ⌘ 없이 눌러요.

워크스페이스, 탭, 분할 창

Ghostty는 탭마다 macOS 창을 하나씩 열어요. 그래서 탭을 프로젝트별로 묶을 수 없고 열린 탭을 한눈에 보기도 어려워요. Chostty는 창을 하나만 쓰고 그 안에서 탭을 세 단계로 나눠요.

  1. 워크스페이스 N

    프로젝트 하나를 담아요. 이름과 색을 붙이고 접거나 순서를 바꿀 수 있어요. 1–8로 바로 가요.

  2. 탭 T

    서버, 테스트, 배포처럼 프로젝트 안에서 하는 일 하나를 맡아요. 잘못 닫았다면 T로 다시 열어요.

  3. 분할 창 D

    셸 하나가 들어가는 칸이에요. Ghostty 분할 단축키로 탭을 원하는 만큼 나누고, 나눈 모양은 탭마다 따로 남아요.

오른쪽 파일 패널에서 Markdown, 소스 코드, 이미지를 고르면 셸 옆에 읽기 전용 탭으로 열려요. 터미널은 그동안에도 계속 돌아가요.

쓰던 Ghostty 설정 그대로

Chostty는 ~/.config/ghostty/config를 읽어요. keybind와 theme 문법이 같고 TERM=xterm-ghostty도 똑같이 설정해요. 화면을 그리는 렌더러, 글꼴, 셸 연동도 Ghostty 코드 그 자체예요. Ghostty와 함께 설치해도 서로 부딪히지 않아요.

테마를 고르면 위쪽 데모 창 색이 바뀌어요.

# ~/.config/ghostty/config
theme = Catppuccin Mocha
font-family = JetBrains Mono
keybind = cmd+d=new_split:right

# Chostty 전용 키 (Ghostty는 무시)
macos-session-persistence = true
auto-update = check

껐다 켜도 하던 자리에서

Chostty는 창 배치를 저장해요. 워크스페이스와 탭, 이름과 색, 분할 모양, 칸마다 열려 있던 디렉터리를 기억해요. 다시 실행하면 배치가 돌아오고 칸마다 원래 디렉터리에서 새 셸이 떠요.

실행 중이던 프로세스, 화면 내용, 스크롤백은 저장하지 않고 터미널 내용을 디스크에 쓰지도 않아요. 셸은 지금 보는 탭에서만 바로 뜨고 다른 탭은 열 때 떠요.

복원
워크스페이스, 탭, 제목, 색, 순서, 분할, 작업 디렉터리
새로 시작
셸, 화면 내용, 스크롤백
끄기
macos-session-persistence = false

설치

  1. 최신 릴리스에서 DMG 파일을 내려받아요.
  2. Chostty를 응용 프로그램 폴더로 옮기고 실행해요. Apple 공증을 받은 앱이라 보안 경고로 막히지 않아요.
  3. 새 버전은 앱이 알아서 확인해요. 끄려면 설정에 auto-update = off를 넣어요.

0.2.15 이하를 쓰고 있다면 앱 ID가 kr.co.devch.chostty로 바뀌었어요. 처음 실행할 때 설정과 저장된 세션을 옮겨 와요. 손쉬운 사용, 자동화 같은 권한은 다시 허용해야 해요.

Chostty 1.0.0 다운로드

Chostty는 Ghostty의 비공식 포크이고 Ghostty 프로젝트와 관계없어요. Ghostty 이름과 로고의 권리는 원래 소유자에게 있어요.
